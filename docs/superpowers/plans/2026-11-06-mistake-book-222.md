# Sổ lỗi 2-2-2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nâng Notebook "Câu làm sai" thành vòng lặp repeat-until-mastered: lỗi chỉ thoát sổ khi trả lời đúng ≥2 lần, ở ≥2 dạng (dimension) khác nhau, vào ≥2 ngày khác nhau.

**Architecture:** Lib thuần `src/lib/mistake-book.ts` quyết định luật 2-2-2 và dimension kế cho phiên luyện; entry notebook mở rộng field `mistake` trong payload JSON (không migration, không domain sync mới); phiên "Luyện lại" tái dùng component flashcard/quiz của review session với nguồn đề = entry chưa mastered; notebook-dashboard thêm trạng thái "Đã đúng n/2" + action.

**Tech Stack:** Next.js 16 App Router, TypeScript strict, Tailwind v4 (token Hanzi), Vitest + Testing Library (jsdom), Playwright (e2e).

**Spec:** `docs/superpowers/specs/2026-11-06-mistake-book-222-design.md`

## Global Constraints

- Luật 2-2-2: mastered ⟺ tồn tại ≥2 câu trả lời ĐÚNG với ≥2 `dimension` khác nhau VÀ ≥2 `date` khác nhau (không yêu cầu mỗi dimension một ngày riêng).
- Câu trả lời SAI không ghi vào `mistake.log` — log chỉ chứa câu đúng.
- `removedManually: true` → ẩn khỏi danh sách active, giữ entry trong lịch sử (không xóa).
- Không migration D1 mới: `mistake` nằm trong `payload` JSON của entry `kind: "wrong"` (payload đã sync qua domain notebook hiện có).
- Không domain sync mới; không đổi format entry ngoài field `mistake` optional.
- Dimension enum: `"meaning" | "listening" | "typing" | "pinyin"`.
- Ngày local dùng cùng quy ước `vnDayString` (progress-store) — mọi hàm thuần nhận `date: string` + `now?: number` qua tham số, không gọi `Date.now()` trong lib thuần.
- UI token Hanzi; touch target ≥ 44px; không hard-code màu.

```ts
// src/lib/mistake-book.ts
/* Sổ lỗi 2-2-2 — luật thuần (spec 2026-11-06 Wave 2 §4).
   Mastered ⟺ ≥2 câu đúng, ≥2 dimension khác nhau, ≥2 ngày khác nhau. */

export type MistakeDimension = "meaning" | "listening" | "typing" | "pinyin";
export type MistakeLogEntry = { date: string; dimension: MistakeDimension };
export type MistakeState = { capturedAt: string; log: MistakeLogEntry[]; removedManually?: boolean };

export const MASTER_DIMENSIONS = 2;
export const MASTER_DAYS = 2;

export function isMastered(state: MistakeState | undefined): boolean {
  if (!state) return false;
  const dates = new Set(state.log.map((l) => l.date));
  const dims = new Set(state.log.map((l) => l.dimension));
  return state.log.length >= MASTER_DIMENSIONS
    && dates.size >= MASTER_DAYS
    && dims.size >= MASTER_DIMENSIONS;
}

export function correctCount(state: MistakeState | undefined): number {
  return state?.log.length ?? 0;
}

export function recordCorrect(
  state: MistakeState | undefined,
  date: string,
  dimension: MistakeDimension,
): MistakeState {
  const base: MistakeState = state ?? { capturedAt: date, log: [] };
  return { ...base, log: [...base.log, { date, dimension }] };
}

/** Ưu tiên dimension chưa có trong log; log đầy → quay lại cái đầu available. */
export function nextDimension(
  state: MistakeState | undefined,
  available: MistakeDimension[],
): MistakeDimension {
  if (available.length === 0) throw new Error("nextDimension: available rỗng");
  const seen = new Set(state?.log.map((l) => l.dimension) ?? []);
  return available.find((d) => !seen.has(d)) ?? available[0];
}
```

```ts
import type { MistakeState } from "@/lib/mistake-book";

/** Ghi state mistake của 1 entry (local); entry không có mistake → bỏ qua. */
export function updateMistakeState(
  entryId: string,
  fn: (s: MistakeState | undefined) => MistakeState,
): void {
  const list = readLocalEntries();
  let changed = false;
  const next = list.map((e) => {
    if (e.id !== entryId) return e;
    const p = e.payload as { mistake?: MistakeState };
    if (!p.mistake) return e;
    changed = true;
    const mistake = fn(p.mistake);
    return { ...e, payload: { ...p, mistake }, updatedAt: new Date().toISOString() };
  });
  if (changed) writeLocalEntries(next);
}

export function markMistakeRemoved(entryId: string): void {
  updateMistakeState(entryId, (s) => (s ? { ...s, removedManually: true } : s));
}
```

```ts
// src/lib/notebook/mistake-hook.ts
import type { MistakeDimension } from "@/lib/mistake-book";
import { recordCorrect } from "@/lib/mistake-book";
import { findLocalEntry, updateMistakeState } from "./entries";
import { vnDayString } from "./mistake-date"; // nếu chưa có: copy 3 dòng date helper từ progress-store

export function findWrongEntryId(q: string, rightZh: string): string | null {
  const e = readLocalEntries().find(
    (x) => x.kind === "wrong"
      && (x.payload as { q?: string }).q === q
      && (x.payload as { right?: { zh: string } }).right?.zh === rightZh
      && !(x.payload as { mistake?: { removedManually?: boolean } }).mistake?.removedManually,
  );
  return e?.id ?? null;
}

export function recordMistakeCorrect(
  payload: { q?: string; right?: { zh?: string } },
  date: string,
  dimension: MistakeDimension,
): void {
  if (!payload.q || !payload.right?.zh) return;
  const id = findWrongEntryId(payload.q, payload.right.zh);
  if (!id) return;
  updateMistakeState(id, (s) => recordCorrect(s, date, dimension));
}
```

2. Lesson/station quiz — trong nhánh câu ĐÚNG, nếu `findWrongEntryId(q, zh)` != null → ghi `dimension` tương ứng dạng câu.
